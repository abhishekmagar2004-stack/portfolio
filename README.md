# Abhishek Magar — Portfolio

A single-file, light-blue portfolio built for SDE internship and entry-level applications.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The entire portfolio (HTML, CSS, JS in one file) |
| `resume.html` | Editable source for the résumé |
| `Abhishek-Magar-Resume.pdf` | One-page résumé linked by every download button |
| `README.md` | This guide |

## View it

Double-click `index.html` — no server or build step needed.

## Before you send it to companies

1. **Placeholder details** — the Nexbyte Systems internship, certifications, and project metrics are realistic placeholders. Update them to match your actual experience.
2. **Résumé** — replace `Abhishek-Magar-Resume.pdf` with your real PDF (keep the same filename), and edit `resume.html` if you want the source to stay in sync.
3. **Project links** — each project currently links to your GitHub profile. Point them at the specific repositories once they are public.
4. **Contact links** — GitHub points to `https://github.com/abhishekmagar2004-stack` and LinkedIn to `https://www.linkedin.com/in/abhishek-magar-a6703035a/`.

## Deploy (free, no build)

- **Netlify** — drag the whole folder onto [app.netlify.com/drop](https://app.netlify.com/drop).
- **GitHub Pages** — push the folder to a repository, then enable Pages for the `main` branch.
- **Vercel** — import the folder as a static project.

## What's included

- Responsive layout with a mobile menu
- Scroll progress bar, active-section nav, reveal-on-scroll animations
- Animated counters and skill bars
- 3D-tilt code card, cursor spotlight, tech marquee
- Project cards with hover glow and measurable outcomes
- Copy-to-clipboard email, validated contact form (opens your mail client)
- One-page A4 résumé PDF
- Accessible: keyboard focus styles, reduced-motion support, Lighthouse 100 / 100 / 100 (accessibility, best practices, SEO)

## Editing tips

- Brand colours live in `:root` at the top of the `<style>` block.
- Sections are labelled with `<!-- ================= NAME ================= -->` comments.
- The "Now" card and statistics are plain HTML — search for `data-count` to change the numbers.
